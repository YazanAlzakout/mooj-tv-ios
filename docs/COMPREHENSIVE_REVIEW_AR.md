# تقرير مراجعة Mooj TV للآيفون

تاريخ التقرير: 25 نوفمبر 2026 — المستودع المستقل `YazanAlzakout/mooj-tv-ios`.

## النتيجة وحدودها

نفّذت مراجعة للكود ومسارات الأزرار والتنقّل والتشغيل والتخزين والتحميل، وأصلحت العيوب المحددة أدناه. هذه **مراجعة مصدر واختبارات منطقية، وليست شهادة بأن التطبيق خالٍ من الأعطال**. لم أشغّل هذه النسخة على آيفون فعلي، ولم أضغط كل زر في واجهة iOS. لا تزال ملاحظات مفتوحة موضحة في التقرير.

الأصل `mooj-tv` لم يتغير. النسخة الجديدة تستخدم واجهات وأصولاً من الأصل، مع تعديلات وإعادة تنظيم لمسارات محددة؛ ليست إعادة كتابة كاملة لكل التطبيق من الصفر.

للمقارنة: خط أساس المراجعة الحالية هو `567175f`. الإصلاحات السابقة موجودة في `cfcb972` و`5d712c5` و`d04e7b7` و`d7e91a2` و`567175f`. لا توجد لدي نتائج كلود بعد، ولذلك لم أضع ادعاء تفوق أو مقارنة تخمينية.

حدود F03: عند عدم وجود أي نسخة محفوظة للقسم، ما زال المسار يرجع قائمة فارغة. التمييز المرئي الكامل بين «لا محتوى» و«فشل أول تحميل» يحتاج متابعة. كما أن F01/F02 لا يعنيان أن جميع عمليات التطبيق أصبحت محمية من كل سباق بين الحسابات؛ عملية تسجيل الدخول/استعادة الجلسة الكاملة تحتاج اختبار إلغاء مستقل.

## التحقق المنفّذ

- **20 اختباراً ناجحاً**: 6 للطابور، 9 للكتالوج/تبديل الجلسة، 3 لدورة حياة VOD، و2 لتنقية التشخيص.
- **مقارنة قبل/بعد:** شغّلت 12 اختبار كتالوج ودورة حياة على مصدر `567175f`: نجح 1، فشل 10، وأُلغي 1 بانتهاء مهلة انتظار الصور. الحالات الـ12 نفسها نجحت بعد التعديل. التشخيص والطابور خارج هذه المقارنة الجزئية.
- **TypeScript:** `npm run typecheck` ناجح.
- **Lint لكل المشروع:** `npm run lint` ناجح، وليس ملفات معدّلة فقط.
- **هوية النسخة:** `npm run verify:ios` ناجح.
- **تصدير JavaScript لـiOS:** `EXPO_NO_TELEMETRY=1 npx expo export --platform ios` ناجح.
- **البناء native:** نجاح سابق على `d7e91a2`؛ لا أنسبه إلى الالتزام الأخير.
- **غير منفّذ:** تشغيل iPhone فعلي، كل زر على محاكي، VoiceOver، قياس FPS/ذاكرة، تشغيل مزوّدك مدة طويلة، تجربة الصوت في محاكي سحابي.

الاختبارات تستعمل الكود الفعلي مع محاكاة حدود الشبكة/SQLite/المشغّل. اختبار الـhook يحاكي ترتيب التأثيرات ولا يشغّل React Native أو AVPlayer؛ نجاحه لا يثبت صحة codec أو touch أو thread native.

الأدلة المختصرة: `docs/review-evidence/before.txt` و`after.txt`. ملفات الاختبار تحت `tests/`، ويمكن تكرارها بـ`npm run test:playback`.

## التحسينات المقترحة بالترتيب

1. إغلاق O01/O02: سبب الكراش وسياسة إخفاء المحتوى أولاً.
2. توحيد كل أدوات المشغّل بصرياً وسلوكياً؛ إبقاء الرجوع سهلاً، وإظهار حالة تحميل/خطأ مع محاولة جديدة مفهومة.
3. تصحيح فهرس البحث والمفضلة ورسائل فشل الحفظ، ثم قياس الأداء على نفس الجهاز ونفس المحتوى.
4. اختبار الانقطاع والعودة والخلفية والتبديل المتكرر مع الصوت والترجمة والسرعة.
5. تأجيل إضافة التسجيل أو البث الخارجي أو أوضاع أخرى؛ المطلوب مشغّل IPTV بسيط وموثوق.
